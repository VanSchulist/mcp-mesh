## Reporting a Vulnerability

Security is paramount in agentic development tooling, especially when supervising child processes.

If you discover a security vulnerability in `mcp-mesh`, please do **NOT** open a public issue.

Instead, please report security vulnerabilities directly to:
* **Contact**: `security@existentialcloud.dev` (or via private security advisory on GitHub).

Please include:
1. Detailed description of the vulnerability.
2. Minimal steps to reproduce or proof-of-concept script.
3. Potential impact on host systems.

We commit to acknowledging your report within 48 hours and providing an estimated timeline for remediation.
